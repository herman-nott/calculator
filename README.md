# Calculator and Unit Converter

This web application features a modern **calculator** with two modes:  
- **Basic calculator** with common arithmetic operations  
- **Engineer calculator** with advanced functions  
- **Converter** for length, mass, and area

---

## Features

### Basic and Engineer Calculator

Supported functions:

| Button | Description               |
|--------|---------------------------|
| +      | Addition                  |
| -      | Subtraction               |
| ×      | Multiplication            |
| ÷      | Division                  |
| +/-    | Toggle sign               |
| %      | Percentage                |
| C      | Clear current input       |
| x!     | Factorial                 |
| \|x\|  | Absolute value            |
| x^n    | Power function            |
| √x     | Square root               |
| 1/x    | Reciprocal                |
| MC     | Memory Clear              |
| MR     | Memory Recall             |
| M+     | Add to memory             |
| M-     | Subtract from memory      |
| MU     | Memory reset              |

### Unit Converter

- Convert length units (meters, centimeters, kilometers, etc.)  
- Convert mass units (kilograms, grams, pounds, etc.)  
- Convert area units (square meters, hectares, acres, etc.)  

---

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/calculator-converter.git
   ```

2. Open ```index.html``` in your web browser.

3. Use the calculator and unit converter directly on the page.
